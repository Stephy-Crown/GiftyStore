**Gifty Store** is a high-fashion, ultra-responsive mobile and desktop e-commerce web application custom-designed for luxury Nigerian fashion boutiques, Owambe couture, Ankara corset dresses, and viral TikTok fashion reels.

---

## 🌟 Key Features

* **Dual-Mode Express Checkout:** Supports automated website Paystack checkout as well as custom WhatsApp price negotiation links.
* **TikTok Fashion Reel Shop:** Interactive vertical video reel cards showcasing outfits in motion with 1-click buy actions.
* **Owner Mobile Admin Dashboard:** Simple mobile dashboard allowing the store owner to upload dress photos directly from her phone camera/gallery and generate custom discounted checkout links.
* **Multi-Currency Support:** Instant real-time conversion between NGN (₦), USD ($), GBP (£), and EUR (€).
* **Inventory Stock Management:** Real-time stock counters with automated `SOLD OUT` overlays and backorder pre-order inquiry flows.
* **Digital Order Receipts:** Automated printable confirmation receipts with 1-click WhatsApp order tracking receipt notifications.
* **Interactive Store Location:** Integrated Google Maps location pinned to Lekki Phase 1, Lagos, Nigeria.

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/Stephy-Crown/GiftyStore.git
cd GiftyStore
```

### 2. Install Dependencies
```bash
bun install
# or
npm install
```

### 3. Run Development Server
```bash
bun run dev
# or
npm run dev
```

The application will launch at `http://localhost:5173/`.

## ⚡ Deployment to Vercel

The project includes a pre-configured `vercel.json` for 1-click Vercel deployments:

1. Import the `Stephy-Crown/GiftyStore` repository on [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Deploy! Every `git push` automatically deploys updates in real-time.
